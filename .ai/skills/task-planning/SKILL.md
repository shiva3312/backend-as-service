# Task Planning Skill

## Objective
Analyze requirements and break down engineering tasks into clear, executable steps adhering to `Industry-grade-be-project-checklist.md`.

## Workflow
1. Review domain requirements and affected modules.
2. Check existing contracts and database schemas.
3. Define step-by-step implementation plan.
4. Identify risk vectors (tenant data leakage, breaking API changes, lock contention).
5. Outline testing & verification strategy.
